## Two Distinct ICP Types

Venzio serves two fundamentally different organisation types from the same platform. Understanding them separately is critical — they configure differently, use the dashboard differently, and need different sales approaches.

## ICP Type 1 — Config-Heavy: Hybrid-Work Companies

| Attribute | Definition |
|---|---|
| Company type | Indian startup or SMB, tech-first, founded post-2018 |
| Headcount | 20–200 employees |
| Work model | Hybrid — 2–4 days/week in-office expected |
| Office situation | Coworking space (WeWork, Awfis, 91Springboard) or leased office |
| Current tools | Zoho Leave, Keka, or Google Sheets for attendance |
| Pain | Pays in-office allowance (₹300–1,000/day) with no way to verify presence |
| How they use Venzio | Registers office WiFi, GPS, IP — dashboard auto-filters presence events to office-matched only |
| Decision maker | Founder, Head of Ops, Office Manager |
| Budget | ₹3,000–15,000/month for a tool that eliminates month-end reconciliation |
| Geography | Bengaluru, Delhi NCR, Mumbai, Hyderabad, Pune, Chennai |

## ICP Type 2 — Config-Light: Field Force Companies

| Attribute | Definition |
|---|---|
| Company type | Insurance distributor, pharma company, FMCG, banking DSA, real estate agency |
| Field staff count | 20–500 field agents |
| Work model | 100% field — agents visit clients at different locations each day |
| Current situation | Agents WhatsApp photos with GPS to manager groups to prove client visits. Zero structure, zero audit trail. |
| Pain | No reliable way to verify agent visited claimed clients. Incentive disputes every month. Manager spends hours reviewing WhatsApp. |
| How they use Venzio | Registers only employee list (no signal config). Dashboard shows all presence events for each agent — complete location diary with timestamps. Manager views Rahul's profile: 9am Sector 44, 11:30am Dwarka, 2pm Vasant Kunj. |
| Decision maker | Branch Manager, Zonal Head, Operations Head |
| Budget | ₹2,000–10,000/month — far cheaper than incentive fraud they currently absorb |
| Geography | Pan-India — Tier 1 and Tier 2 cities |

## Anti-ICP

| Segment | Why to avoid now |
|---|---|
| Fully remote companies | No physical presence to track — wrong product |
| Enterprises 500+ | Long procurement, IT security reviews, SSO requirements — not our product yet |
| Manufacturing/factory | Biometric hardware is standard and appropriate — Venzio is not a replacement |
| Companies outside India | Different labour law, currency, compliance — after 500 domestic customers |

## ICP Qualification Checklist

For Type 1 (hybrid-work):
- Does the company have a hybrid policy with monetary attendance incentive?
- Is current tracking manual (Zoho, spreadsheet, WhatsApp)?
- Is the decision maker a founder or ops lead with direct budget authority?
- Is the company 15–200 employees?

For Type 2 (field force):
- Does the company pay field incentives based on number of client visits?
- Is current proof of visit via photo/WhatsApp or paper log?
- Does the manager currently spend time manually verifying agent activity?
- Is the field team 20+ agents?

4/4 on either checklist = hot lead. 3/4 = worth pursuing. 2/4 or below = not the right time.
